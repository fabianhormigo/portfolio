Search, model, tools and validation, in plain sight. Start it in your browser or run it on your machine with Ollama; otherwise real runs are replayed.

How to run it live

OllamaLocal models: qwen2.5, llama3.1 and nomic-embed-text.
RAGChromaDB and BM25 with version filter and validated quote.
Agent + MCPThe model picks tools from a real MCP server.
Local serverPlain Python; only listens on your machine.
git clone https://github.com/fabianhormigo/portfolio
cd portfolio
pip install -r requirements.txt
ollama pull qwen2.5:7b-instruct
ollama pull nomic-embed-text
python vivo/servidor.py

Then open http://127.0.0.1:8800/en/vivo.html. Small models make mistakes: that is why every answer shows its source and what was validated.
