Ask the dashboard without invented numbers

Across 479,498 public tenders, how do you ask in plain language without the model making numbers up?

The problem

A filtered dashboard doesn't answer questions; a free chat does, but may invent.

The solution

  • Code computes the figures for the active filter.
  • The model only writes and proposes a JSON action.
  • The action is validated before it is applied.

What it brings

You ask it like an analyst, and the chart comes from the data, not the model.

Ask and watch the chart

Answers recorded with a local model; the chart is drawn from real data.

Limits. Recording exposed two bugs (an invented accent in a sector name and JSON in the text), fixed with validation. A 7B model can still get comparisons wrong.
