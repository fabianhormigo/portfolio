¿Qué pasa si un webhook llega dos veces, si falla a mitad o si el fichero viene mal?

El problema

Las integraciones fallan en los bordes: reintentos, duplicados, datos incompletos.

La solución

  • Cada evento se aplica una sola vez.
  • Si algo falla a mitad, se revierte entero.
  • Reintentos con espera creciente solo para errores temporales.
  • Control de calidad de ficheros antes de usarlos.

Qué aporta

El proceso se puede relanzar sin miedo y los errores se ven.

Envía el mismo evento dos veces

Simulación del flujo: el duplicado se ignora y el evento erróneo no deja rastro.
