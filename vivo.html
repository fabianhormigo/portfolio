Cómo ejecutarlo en vivo

OllamaModelos locales: qwen2.5, llama3.1 y nomic-embed-text.
RAGChromaDB y BM25 con filtro por versión y cita validada.
Agente + MCPEl modelo elige herramientas de un servidor MCP real.
Servidor localPython sin framework; solo escucha en tu equipo.
git clone https://github.com/fabianhormigo/portfolio
cd portfolio
pip install -r requirements.txt
ollama pull qwen2.5:7b-instruct
ollama pull nomic-embed-text
python vivo/servidor.py

Después abre http://127.0.0.1:8800/vivo.html. Los modelos pequeños se equivocan: por eso cada respuesta muestra de dónde sale y qué se ha validado.
